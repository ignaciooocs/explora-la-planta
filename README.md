# Explora la planta

Actividad digital accesible de Ciencias Naturales para 3.º básico. Trabaja el OA 1: las necesidades de las plantas y su relación con la raíz, el tallo y las hojas.

Es un solo archivo (`index.html`), sin instalación, sin cuentas y sin envío de datos. Ofrece tamaño de texto de 100 a 300 %, tres combinaciones de colores, lectura en voz alta, uso con teclado o pantalla táctil y compatibilidad con lectores de pantalla.

La tipografía es Atkinson Hyperlegible, de Braille Institute, bajo licencia SIL Open Font (ver `LICENCIA-TIPOGRAFIA-OFL.txt`).
